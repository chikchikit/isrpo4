# Общее описание решения

Проект состоит из двух модулей с функциями для геометрических расчётов и двух модулей с unit-тестами.

## Модули

- `rectangle.py` - вычисление площади и периметра прямоугольника по двум сторонам.
- `triangle.py` - вычисление площади треугольника по стороне и проведённой к ней высоте, периметра по трём сторонам.

## Тестирование

Для каждого модуля написан отдельный файл с тестами на базе стандартной библиотеки `unittest`:

- `test_rectangle.py` - 10 тестов (по 5 на площадь и периметр);
- `test_triangle.py` - 9 тестов (4 на площадь, 5 на периметр).

Тесты проверяют нулевые значения, целые и дробные числа, частные случаи фигур (квадрат, равносторонний и прямоугольный треугольник) и независимость результата от порядка аргументов. Подробный план тестирования описан в `test_plan.md`.

## Известные ограничения

Функции не проверяют входные данные: отрицательные числа и невозможные наборы сторон треугольника (например, 1, 1, 100) не отклоняются. Подобные случаи не входят в область текущих тестов.
