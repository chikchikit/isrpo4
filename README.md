# isrpo4

Проект для вычислений при работе с геометрическими фигурами с набором unit-тестов. В нём реализованы функции для нахождения площади и периметра прямоугольника и треугольника, а также тесты, проверяющие их корректность (лабораторная работа №4, продолжение лабораторной работы №2).

## Состоит из

- *rectangle.py* - функции для прямоугольника
- *triangle.py* - функции для треугольника
- *test_rectangle.py* - unit-тесты для прямоугольника
- *test_triangle.py* - unit-тесты для треугольника
- *docs/* - документация проекта:
  - *about.md* - общее описание решения
  - *functions.md* - описание каждой функции с примерами вызова
  - *test_plan.md* - план тестирования и таблица тест-кейсов
  - *history.md* - история изменения проекта с хешами коммитов (кроме последней записи)
  - *screenshots/* - скриншоты запуска тестов
- *README.md* - основная информация о проекте

## Реализованные функции

- площадь прямоугольника
- периметр прямоугольника
- площадь треугольника
- периметр треугольника

## Запуск тестов

Из корня репозитория:

```
python -m unittest -v test_rectangle.py test_triangle.py
```

Ожидаемый результат: `Ran 19 tests ... OK`.
